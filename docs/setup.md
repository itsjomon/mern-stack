# Setting Up Local Development Environment

A quick guide to setting up your environment to build and run HTML, CSS and JavaScript projects.

## Install Web Browser

Download and install **[Google Chrome](https://www.google.com/chrome/)** for inspecting elements, debugging JavaScript console output and rendering web pages.

## Install VS Code

1. Download and install **[Visual Studio Code](https://code.visualstudio.com/)** for your operating system.
2. Open VS Code, go to the Extensions tab (`Ctrl+Shift+X` on Windows/Linux or `Cmd+Shift+X` on macOS) and install the **Live Server** extension (by Ritwick Dey).

## Running Your Web Pages

1. Open your project folder in VS Code.
2. Open any `.html` file.
3. Click **Go Live** at the bottom-right status bar (or right-click inside the `.html` file editor and select **Open with Live Server**).
4. Your default web browser will open automatically and refresh whenever you save changes.
